# Jargon-to-Plain-Language Reference Guide

A comprehensive list of common transit planning terms and their plain English equivalents, designed for advocates translating technical reports for general audiences.

## General Planning Terms

| Technical Term | Plain English |
|----------------|---------------|
| Level of Service (LOS) | Traffic flow rating (A = free flow, F = gridlock) |
| Vehicle Miles Traveled (VMT) | How much people drive |
| Environmental Impact Statement (EIS) | Environmental review report |
| Right-of-way | Public land along roads or rail lines |
| Mode share | How people travel (car, bus, bike, walk) |
| Induced demand | More roads can lead to more traffic |
| Capacity | How many vehicles or people a road/transit can handle |
| Congestion | Traffic jams or slow traffic |
| Mitigation | Solutions to reduce negative impacts |
| Stakeholder | Person or group affected by a project |
| Scoping | Early planning phase to identify key issues |
| Alternatives analysis | Comparing different options for a project |
| Preferred alternative | The option the planners recommend |
| Record of Decision (ROD) | Final approval document |

## Transit-Specific Terms

| Technical Term | Plain English |
|----------------|---------------|
| Fixed-guideway | Dedicated track or lane for buses/trains |
| Headway | Time between buses or trains |
| Boardings | Number of people getting on transit |
| Ridership | Number of people using transit |
| Farebox recovery | Percentage of operating costs covered by fares |
| Paratransit | Door-to-door service for people with disabilities |
| Bus rapid transit (BRT) | Fast bus service with dedicated lanes |
| Light rail | Modern streetcar or tram system |
| Commuter rail | Train service connecting suburbs to city |
| Transit-oriented development (TOD) | Building homes and businesses near transit stops |
| Last-mile connection | Getting from transit stop to final destination |

## Environmental Terms

| Technical Term | Plain English |
|----------------|---------------|
| NEPA | National Environmental Policy Act (environmental review law) |
| Categorical Exclusion (CE) | Project with minimal environmental impact |
| Environmental Assessment (EA) | Shorter environmental review |
| Finding of No Significant Impact (FONSI) | Decision that a project won’t harm the environment |
| Wetland | Swamp, marsh, or bog |
| Floodplain | Area likely to flood |
| Noise contour | Map showing noise levels around a project |
| Air quality conformity | Meeting clean air standards |
| Section 4(f) | Law protecting parks, historic sites, and wildlife refuges |

## Economic Terms

| Technical Term | Plain English |
|----------------|---------------|
| Benefit-cost analysis (BCA) | Comparing project benefits to costs |
| Net present value (NPV) | Total value of a project over time |
| Cost-effectiveness | Getting the most benefit per dollar spent |
| Economic impact | Effect on jobs, income, and local economy |
| Value capture | Using increased property values to fund transit |
| Public-private partnership (P3) | Government and business working together |
| Grant | Money given for a specific purpose |
| Matching funds | Money the local government must contribute |

## How to Use This Guide

1. When reading a technical report, highlight any jargon you encounter.
2. Look up the term in this guide and replace it with the plain English equivalent.
3. If the term is not listed, search online or ask a subject matter expert for a simple explanation.
4. Always check that the plain English version accurately reflects the original meaning.
