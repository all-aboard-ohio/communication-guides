# Example Before/After Translations

This directory contains real-world examples of Ohio planning documents translated for general audiences using the [Translating Technical Reports guide](../guides/translating-technical-reports/README.md).

## Purpose

These examples demonstrate how to apply the key techniques—finding extraction, jargon elimination, visual summarization, and compelling writing—to actual documents. Use them as models for your own translations.

## Examples

| Original Document | Translated Summary | Key Techniques Used |
|-------------------|--------------------|---------------------|
| [NEPA Environmental Assessment (Sample)](nepa-assessment-original.md) | [One-Page Summary](nepa-assessment-summary.md) | Finding extraction, jargon elimination, headline writing |
| [Feasibility Study (Sample)](feasibility-study-original.md) | [Two-Page Summary](feasibility-study-summary.md) | Visual summarization, call to action |
| [Traffic Impact Study (Sample)](traffic-impact-original.md) | [Infographic Summary](traffic-impact-summary.md) | Chart creation, plain language |

## How to Use

1. Read the original document to understand the technical content.
2. Compare it with the translated summary to see how jargon was replaced and findings were prioritized.
3. Note the visuals used and how they simplify data.
4. Adapt the approach for your own documents.
