# AAO Communication Guides

A library of advocacy communication guides for All Aboard Ohio campaigns.

These guides help advocates clearly and confidently communicate the case for passenger rail investment across a variety of audiences — from fiscal-conservative policymakers to skeptical community members.

## Guide Topics

| Guide | Description |
|---|---|
| [Economic Data](guides/economic-data/) | ROI, fiscal impact, and job creation arguments |
| [Ridership Forecasts](guides/ridership-forecasts/) | Making projections accessible and credible |
| [Successful Rail Systems](guides/successful-rail-systems/) | Real-world case studies that moved policy |
| [Property Values & Development](guides/property-values-development/) | TOD data and community investment framing |
| [Translating Technical Reports](guides/translating-technical-reports/) | Making dense research digestible |
| [Data Visualization](guides/data-visualization/) | Maps, charts, and interactive dashboards |
| [Creating Case Studies](guides/case-studies/) | Local stories with measurable impact |
| [Parking Lot to Downtown Density](guides/parking-lot-to-density/) | Land use change justified by passenger rail |
