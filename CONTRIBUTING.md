# Contributing to AAO Communication Guides

Thank you for contributing to the All Aboard Ohio communication guide library. This document explains how to add or improve a guide.

## Getting Started

1. Browse the [open issues](https://github.com/all-aboard-ohio/communication-guides/issues) — issues labeled `good-first-issue` are designed for new contributors.
2. Comment on an issue to claim it before starting work.
3. Fork the repository and create a branch named `guide/<topic-slug>` (e.g., `guide/economic-data`).
4. Use the [guide template](templates/guide-template.md) as your starting point.
5. Submit a pull request referencing the issue number.

## Guide Standards

Each guide should include:
- **Goals** — what the advocate should be able to do after reading
- **Key Talking Points** — the main arguments to make
- **Resources** — links, data sources, and templates
- **Example Use Case** — a concrete scenario showing the guide in action

See [templates/guide-template.md](templates/guide-template.md) for the full template.

## Style Guidelines

- Write for a non-expert audience. Avoid jargon or define it on first use.
- Prefer specific, cited data over general claims.
- Keep guides focused — if it grows beyond 1,500 words, consider splitting it.
- Use sentence case for headings.

## File Naming

- Guide folders: `guides/<topic-slug>/`
- Main guide file: `guides/<topic-slug>/README.md`
- Supporting files: `guides/<topic-slug>/<descriptive-name>.md`
